Installation sur Android

  1. Touchez le bouton Android ci-dessus, puis ouvrez le fichier une fois téléchargé.
  2. Android demandera d'autoriser l'installation : touchez Paramètres, puis activez Autoriser cette source.
  3. Revenez en arrière et touchez Installer. L'application apparaît ensuite avec vos autres applications.
